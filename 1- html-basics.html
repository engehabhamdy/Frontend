3. القوائم (Lists)

قائمة غير مرتبة (Unordered List - ul):

  • عنصر HTML (li)
  • عنصر CSS (li)
  • عنصر JavaScript (li)

قائمة مرتبة (Ordered List - ol):

  1. الخطوة الأولى: تعلم HTML
  2. الخطوة الثانية: تعلم CSS
  3. الخطوة الثالثة: تعلم JS

4. الحاويات والمُعرفات (Containers, ID & Class)

تُستخدم <div> كحاوية لتجميع العناصر لتنسيقها بواسطة CSS.

هذا الصندوق أخذ تنسيقاً خاصاً عبر كلاس: class="custom-card"

هذا النص له مُعرف فريد لا يتكرر: id="unique-header"

5. اختصار التعليقات (Comments)

لكتابة تعليق لا يظهر في الصفحة، استخدم الاختصار: Ctrl + / في المحرر.
