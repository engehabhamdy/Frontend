الدليل المرجعي الشامل: من GitHub إلى كود المشروع

المرحلة الأولى: خطوات موقع GitHub (تُنَفَّذ مرة واحدة لكل مشروع)

1. الدخول وإنشاء مستودع جديد

قم بفتح موقع GitHub وسجل دخولك، ثم اضغط على علامة (+) أعلى اليمين واختر New repository.

2. تسمية المستودع

اكتب اسم المشروع في خانة Repository name (مثلاً: Frontend) واختر ما إذا كان Public أو Private.

3. الاستثناء المهم لإنشاء مستودع فارغ

تأكد تماماً من عدم وضع صح على خيار Add a README file ليبقى المستودع خالياً تماماً فتظهر لك شاشة الأوامر التعليمية المباشرة.

4. التأكيد وتنسيق الرابط

اضغط على الزر الأخضر Create repository وانسخ رابط المستودع الخاص ببروفايلك والذي يكون بالشكل التالي:

https://github.com/engehabhamdy/Frontend.git

المرحلة الثانية: الربط والرفع لأول مرة (تُنَفَّذ مرة واحدة في الـ Terminal)

1. إنشاء ملف التعريف بالمشروع

ينشئ ملف README.md ويكتب بداخله عنوان المشروع ليظهر كواجهة على GitHub.

echo "# Frontend" >> README.md

2. تفعيل نظام تتبع Git داخل المجلد

يحول المجلد الحالي بداخل جهازك إلى مستودع محلي يتبعه نظام Git وينشئ مجلد .git المخفي.

git init

3. تجهيز ملف README الأول

يضع ملف README.md في منطقة التجهيز تمهيداً لحفظه.

git add README.md

4. التوثيق والحفظ الأول (Commit)

يلتقط صورة للنسخة الأولى مع إرفاق الرسالة التوضيحية الأولى.

git commit -m "first commit"

5. توحيد اسم الفرع الرئيسي

يعدل اسم الفرع الأساسي في مشروعك ليصبح main ليتطابق مع معايير GitHub.

git branch -M main

6. ربط المجلد المحلي بمستودع GitHub

يربط مجلد جهازك برابط المستودع الفارغ على السيرفر ويسمي الرابط origin.

git remote add origin https://github.com/engehabhamdy/Frontend.git

7. الرفع الأول وتثبيت المسار

يرفع الملفات ويحفظ المسار بحيث تتمكن مستقبلاً من استخدام git push فقط.

git push -u origin main

المرحلة الثالثة: الروتين اليومي عند إضافة كود جديد أو تعديل ملفات

1. تجميع وتجهيز جميع التعديلات

تُجمّع النقطة (.) كافة الملفات والتعديلات الجديدة داخل المجلد دفعة واحدة.

git add .

2. حفظ التعديلات محلياً بكتلة وصفيّة

يحفظ لقطة جديدة من المشروع بداخل جهازك مع إعطائها اسماً يعبر عن نوع التعديل.

git commit -m "اكتب هنا وصفاً دقيقاً لما قمت بتعديله"

3. إرسال الكود المباشر إلى السيرفر

ينقل كل الـ Commits المجهزة من جهازك إلى موقع GitHub فوراً.

git push

المرحلة الرابعة: أوامر الفحص والمتابعة والتراجع

1. أمر كشف حالة المشروع (git status)

يعرض لك التقرير الفعلي للملفات المعدلة والتجهيزات:

  • اللون الأحمر: ملفات معدلة أو جديدة لم تُجهز بـ git add . بعد.
  • اللون الأخضر: ملفات مجهزة وجاهزة لأمر git commit.
git status

2. أوامر التراجع (git reset)

يستخدم لإلغاء الخطوات الأخيرة حسب حاجتك:

  • إلغاء التجهيز (إلغاء git add): git reset
  • فك آخر commit مع الحفاظ على الكود في التجهيز: git reset --soft HEAD~1
  • فك آخر commit وإرجاعه لتعديل عادي (أحمر): git reset --mixed HEAD~1
  • التراجع الكامل ومسح آخر تعديلات نهائياً (خطر): git reset --hard HEAD~1
💡 تذكر دائماً: هذا الملف مرجع دائم لك، افتحه في المتصفح في أي وقت لتراجع منه الأوامر!
