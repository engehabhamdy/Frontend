الدليل الكامل لأوامر Git & GitHub

أولاً: خطوات إنشـاء المشروع وربطه بـ GitHub لأول مرة

1. إنشاء ملف الواجهة الرئيسي

ينشئ ملف README.md ويكتب بداخل العنوان الشارح للمشروع.

echo "# Frontend" >> README.md

2. تهيئة وتفعيل Git للمجلد

يحول المجلد الحالي على جهازك إلى مستودع محلي يتبعه نظام Git.

git init

3. تجهيز ملف README

يضيف الملف للتجهيز قبل الحفظ المباشر.

git add README.md

4. حفظ التغييرات الأولى (Commit)

يلتقط صورة للنسخة الأولى مع إرفاق رسالة توضيحية.

git commit -m "first commit"

5. ضبط اسم الفرع الرئيسي

يضمن تسمية الفرع الأساسي باسم main ليتوافق مع GitHub.

git branch -M main

6. ربط المستودع المحلي بالسيرفر

يربط مشروعك على الجهاز بمستودع GitHub الفارغ الذي أنشأته.

git remote add origin https://github.com/engehabhamdy/Frontend.git

7. الرفع الأول إلى GitHub

يرفع الملفات ويحفظ المسار التلقائي للمرات القادمة.

git push -u origin main

ثانياً: الروتين اليومي عند إضافة كود جديد أو تعديل المشروع

1. تجميع وتجهيز كل الملفات المعدلة

النقطة تعني تجميع كل التغييرات في المجلد دفعة واحدة.

git add .

2. حفظ التعديل محلياً مع اسم توضيحي

احرص على كتابة وصف واضح يعبر عن التعديل الذي قمت به.

git commit -m "اكتب هنا وصف التعديل"

3. الرفع المباشر إلى GitHub

يرفع كل التعديلات المحفوظة فوراً على الموقع.

git push
💡 نصيحة عمل: استخدم الجزء الأول مرة واحدة فقط عند إنشاء مشروع جديد، أما الجزء الثاني فهو الذي ستكرره دائماً مع كل خطوة عمل وتعديل في المشروع.
